## Customization

### Change Model Quality

In `artwork_generation_service.py`:

```python
class ArtworkGenerator:
    def __init__(self):
        self.model = AIModel.QUALITY  # Change to TURBO or STANDARD
```

### Adjust Prompt Style

Customize the style templates:

```python
self.templates[ArtworkType.MUSIC_COVER] = {
    "width": 1024,
    "height": 1024,
    "style_prompt": "your custom style here...",
}
```

### Add More Artwork Types

1. Add to `ArtworkType` enum:
```python
class ArtworkType(str, Enum):
    MY_TYPE = "my_type"
```

2. Add template:
```python
self.templates[ArtworkType.MY_TYPE] = {
    "width": 1920,
    "height": 1080,
    "style_prompt": "...",
}
```

3. Add generator method:
```python
async def generate_my_type(self, title: str) -> List[GeneratedArtwork]:
    prompt = ArtworkPrompt(text=f"...", style="...", mood="...")
    return await self.generate_artwork(
        prompt,
        artwork_type=ArtworkType.MY_TYPE,
        num_outputs=3,
    )
```

## Troubleshooting

### "Connection timeout"
```
→ Pollinations might be temporarily slow
→ Retry after 30 seconds
→ Check your internet connection
```

### "Image not loading in browser"
```
→ Pollinations CDN might be cached
→ Try refreshing the page
→ Check browser console for CORS errors
```

### "Bad quality images"
```
→ Try adjusting the prompt (add more detail)
→ Use more specific genres/moods
→ Try adding artist references
```

### "Rate limited"
```
→ Pollinations has generous rate limits
→ Space out requests by 0.5 seconds (built-in)
→ Use different seeds for variations
```
