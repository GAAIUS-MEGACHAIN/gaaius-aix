📋 DETAILED FEATURE BREAKDOWN:
==============================

1. FILE SYSTEM API:
   Methods:
   - POST /projects - Create project
   - GET /projects/{id} - Get project
   - GET /projects/{id}/files - List files
   - POST /projects/{id}/files - Create file
   - GET /projects/{id}/files/{path} - Read file
   - PUT /projects/{id}/files/{path} - Update file
   - DELETE /projects/{id}/files/{path} - Delete file
   - GET /projects/{id}/tree - Get file tree
   
2. CODE EXECUTION API:
   Methods:
   - POST /projects/{id}/execute - Run code
   - POST /projects/{id}/terminal - Execute terminal command
   - GET /projects/{id}/output - Get execution output
   - POST /projects/{id}/stop - Stop execution
   - GET /projects/{id}/processes - List running processes
   
3. PACKAGE MANAGEMENT API:
   Methods:
   - POST /projects/{id}/packages/install - Install package
   - DELETE /projects/{id}/packages/{name} - Uninstall package
   - GET /projects/{id}/packages - List installed packages
   - GET /projects/{id}/packages/available - Search available packages

4. ENVIRONMENT API:
   Methods:
   - GET /projects/{id}/env - Get env variables
   - PUT /projects/{id}/env - Set env variables
   - POST /projects/{id}/env/{key} - Set single env var
   - DELETE /projects/{id}/env/{key} - Delete env var

5. EXECUTION OUTPUT API:
   WebSocket: /ws/projects/{id}/output
   - Real-time stdout/stderr streaming
   - Process state changes
   - Error notifications
