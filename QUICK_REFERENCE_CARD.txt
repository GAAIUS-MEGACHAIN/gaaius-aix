## 🎯 Usage Patterns

### Pattern 1: Direct Python
```python
from backend.build_system_enterprise import BuildOrchestrator

orchestrator = BuildOrchestrator()
success, job_id, msg = orchestrator.submit_build(config)
status = orchestrator.check_job_status(job_id)
```

### Pattern 2: REST API
```bash
# Start server
python -m uvicorn backend.build_api_enterprise:app --port 8000

# Submit build
curl -X POST http://127.0.0.1:8000/api/builds/submit \
  -H "Content-Type: application/json" \
  -d '{"framework": "tauri", ...}'

# Check status
curl http://127.0.0.1:8000/api/builds/job_id/status
```

### Pattern 3: Integration with GAAIUS
```python
# In your GAAIUS code generation endpoint:
from backend.build_system_enterprise import BuildOrchestrator

@app.post("/generate-and-build")
def generate_and_build(request):
    # Generate project
    project_path = generate_project(request)
    
    # Build it
    orchestrator = BuildOrchestrator()
    config = BuildConfig.from_project(project_path)
    success, job_id, msg = orchestrator.submit_build(config)
    
    # Return job tracking info
    return {"job_id": job_id, "status_url": f"/api/builds/{job_id}/status"}
```

## 🚨 Quick Troubleshooting

**System validation fails:**
- Verify Node.js, npm, Cargo, Docker are installed
- Run: `python run_production_test.py` to diagnose

**Build doesn't start:**
- Check logs in `logs/builds/{job_id}.log`
- Verify project structure matches framework requirements
- Check that all dependencies are available

**API doesn't respond:**
- Verify server is running
- Check port 8000 is available
- Review FastAPI logs for errors

**Build gets stuck:**
- Check artifact storage has space
- Verify timeout settings (default: 30 min)
- Check Docker is running (for Flutter)
