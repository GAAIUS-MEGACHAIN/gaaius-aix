┌──────────────────────────────────────────────────────────────────────────────┐
│ WHAT HAPPENS NOW                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

USER UPLOADS VIDEO:
  ✅ Runs through 4-layer validation
  ✅ Layer 1: Checks if user is blocked
  ✅ Layer 2: Checks for duplicates
  ✅ Layer 3: Runs ML keyword detection
  ✅ Layer 4: Gets Groq AI classification

DECISION MADE:
  Risk > 0.8:     → BLOCKED (HTTP 403, upload fails)
  Risk 0.6-0.8:   → FLAGGED (stored, marked for review)
  Risk 0.4-0.6:   → FLAGGED (stored, marked for review)
  Risk 0.2-0.4:   → ALLOWED (upload accepted)
  Risk < 0.2:     → ALLOWED (upload accepted)

IF BLOCKED:
  ✅ Violation counted (1/3)
  ✅ After 3 violations: Account blocked
  ✅ User can appeal: Submit reason
  ✅ Admin reviews: Approve/reject
