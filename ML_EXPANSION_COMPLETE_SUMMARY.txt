OPTION 1: Add Sentiment Analysis to React (15 minutes)
========================================================

1. Install package:
   npm install @xenova/transformers

2. Create hook (src/hooks/useSentiment.js):
   ```javascript
   import { pipeline } from "@xenova/transformers";
   import { useEffect, useRef } from "react";

   export function useSentiment() {
     const modelRef = useRef(null);
     
     useEffect(() => {
       pipeline('text-classification').then(
         m => modelRef.current = m
       );
     }, []);
     
     return async (text) => {
       if (!modelRef.current) return null;
       const result = await modelRef.current(text);
       return result[0];
     };
   }
   ```

3. Use in component:
   ```javascript
   function ReviewAnalyzer() {
     const analyzeSentiment = useSentiment();
     const [text, setText] = useState("");
     const [result, setResult] = useState(null);
     
     return (
       <div>
         <textarea value={text} onChange={e => setText(e.target.value)} />
         <button onClick={async () => {
           const res = await analyzeSentiment(text);
           setResult(res);
         }}>Analyze</button>
         {result && <p>{result.label}: {result.score.toFixed(2)}</p>}
       </div>
     );
   }
   ```

DONE! You now have sentiment analysis in your React app.

OPTION 3: Create FastAPI ML Backend (1 hour)
================================================

1. Install packages:
   pip install fastapi uvicorn transformers torch

2. Create app.py:
   ```python
   from fastapi import FastAPI
   from transformers import pipeline
   from fastapi.middleware.cors import CORSMiddleware

   app = FastAPI()
   
   app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"])
   
   classifier = pipeline("sentiment-analysis")
   summarizer = pipeline("summarization")
   
   @app.post("/analyze")
   async def analyze(text: str):
       return classifier(text)[0]
   
   @app.post("/summarize")
   async def summarize(text: str):
       return summarizer(text, max_length=100)[0]
   ```

3. Run:
   uvicorn app:app --reload

4. Test:
   curl -X POST "http://localhost:8000/analyze?text=I love this"

DONE! Backend ML API ready.
