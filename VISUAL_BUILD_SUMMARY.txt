To Launch:

1. Set Environment Variables
   export MONGODB_URI="..."
   export STRIPE_API_KEY="..."
   export JWT_SECRET="..."

2. Install Dependencies
   pip install -r requirements.txt
   pip install -r backend/subscription_requirements.txt
   pip install -r backend/ecommerce_requirements.txt

3. Start Server
   python -m uvicorn backend.server:app --host 0.0.0.0

4. Access API
   http://localhost:8000/docs (interactive docs)

5. Test Endpoints
   # Create subscription tier
   curl -X POST http://localhost:8000/api/subscriptions/tiers
   
   # Create product
   curl -X POST http://localhost:8000/api/shop/products
   
   # Start video collaboration
   curl -X POST http://localhost:8000/api/duet/sessions
