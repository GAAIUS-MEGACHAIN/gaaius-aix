## Quick Start - PRODUCTION DEPLOYMENT

### 1. Start the Unified Server

```bash
python -m backend.unified_server
```

**Or with uvicorn directly:**

```bash
python -m uvicorn backend.unified_server:app --host 0.0.0.0 --port 8000 --reload
```

**Output:**
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete
```

### 2. Access the API

**Swagger UI (Interactive Docs):**
```
http://localhost:8000/docs
```

**Alternative Docs:**
```
http://localhost:8000/redoc
```

**Health Check:**
```bash
curl http://localhost:8000/health
```

### 3. Test Endpoints

**List Frameworks:**
```bash
curl http://localhost:8000/api/frameworks
```

**Run ML Inference (Sentiment):**
```bash
curl -X POST http://localhost:8000/api/ml/sentiment \
  -H "Content-Type: application/json" \
  -d '{"text": "This is amazing!"}'
```

**List Models:**
```bash
curl http://localhost:8000/api/models
```

### 4. Use CLI Tools

**Build a React app:**
```bash
python -m backend.ml_cli build create --framework react --name my-app
```

**Run ML inference:**
```bash
python -m backend.ml_cli ml infer --model distilbert --text "Hello world"
```

**Check system status:**
```bash
python -m backend.ml_cli system status
```
