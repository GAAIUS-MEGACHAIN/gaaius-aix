## 🎓 HOW IT WORKS (Complete Lifecycle)

### User Login Flow
```
1. User opens http://localhost:3000 in browser
   ↓
2. React app loads (from npm build)
   ↓
3. User enters credentials in login form
   ↓
4. Frontend validates with Zod schema
   ↓
5. Axios sends POST /api/auth/login
   ↓
6. Backend route handler receives request
   ↓
7. Authentication service processes:
   - Looks up user in MongoDB
   - Validates password with Bcrypt
   - Generates JWT token
   ↓
8. Returns JWT + user data to frontend
   ↓
9. Frontend stores JWT in localStorage
   ↓
10. Updates Zustand store (global state)
   ↓
11. Redirects to dashboard
   ↓
12. All future requests include JWT in headers
   ↓
13. Backend validates JWT on each request
   ↓
14. Grants access to protected resources
   ↓
15. User sees personalized dashboard
```
