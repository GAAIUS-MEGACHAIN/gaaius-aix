## 🚀 USAGE EXAMPLES

### Get NFT Overview
```bash
curl -X GET "http://localhost:8000/api/v1/advanced-analytics/nft/overview"
```

### Track a Donation
```bash
curl -X POST "http://localhost:8000/api/v1/advanced-analytics/donations/track-donation" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "supporter_123",
    "metadata": {
      "creator_id": "creator_456",
      "amount": 50.00,
      "monthly_amount": 25.00
    }
  }'
```

### Get Tournament Completion Rate
```bash
curl -X GET "http://localhost:8000/api/v1/advanced-analytics/tournaments/completion-rates"
```

### Track Live Purchase
```bash
curl -X POST "http://localhost:8000/api/v1/advanced-analytics/live-shopping/track-purchase" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "buyer_789",
    "metadata": {
      "amount": 99.99,
      "quantity": 3,
      "session_id": "session_123"
    }
  }'
```
